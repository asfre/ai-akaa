# 📌 项目简介

本项目旨在构建一个基于 Vue2 和 Element UI 的轻量级后台管理系统，其核心功能类似于“小型 ChatGPT 管理面板”。用户可以在前端界面中输入问题，并获取由 AI 提供的答案。此外，系统支持查看历史提问记录、统计问答数据等功能。

该项目不仅满足当前开发学习的需求，也为未来扩展至企业级应用打下坚实的基础。

# 🔧 开发环境搭建指南

## 初始化项目

```bash

vue create ai-knowledge-admin
```

## 安装必要依赖

```bash

cd ai-knowledge-admin
npm install element-ui axios mockjs echarts vuex@3 vue-router@3
```

## 启动本地开发服务器

```bash

npm run serve
```

## 构建生产环境包

```bash

npm run build
```
