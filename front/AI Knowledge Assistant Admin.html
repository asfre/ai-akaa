AI Knowledge Assistant Admin

📌 项目简介

本项目旨在构建一个基于 Vue2 和 Element UI 的轻量级后台管理系统，其核心功能类似于“小型 ChatGPT 管理面板”。用户可以在前端界面中输入问题，并获取由 AI 提供的答案。此外，系统支持查看历史提问记录、统计问答数据等功能。

该项目不仅满足当前开发学习的需求，也为未来扩展至企业级应用打下坚实的基础。

🎯 项目目标

当前阶段目标

  • 实现基本的聊天交互界面，包括消息发送与接收；

  • 使用 Mock.js 模拟后端接口行为；

  • 构建清晰的状态管理体系（Vuex）用于维护会话及统计数据；

  • 初步集成图表展示能力（ECharts），呈现简单的分析结果；

中长期发展愿景

  • 接入真实的 AI 大模型 API，实现智能化服务；

  • ~~引入数据库存储机制（如 IndexedDB 或远程服务器），持久化用户的对话记录；~~本地存储 sql 数据库

  • 支持多角色权限控制体系；

  • 迁移到 Vue3 + TypeScript 技术栈，提升代码质量和可维护性；

  • 增强系统的安全性、稳定性和响应速度；

  • 扩展更多数据分析维度，增强可视化效果；

💡 功能规划

模块 描述
登录认证 简单的身份验证流程，通过 Token 控制访问权限

🔧 开发环境搭建指南

初始化项目


vue create ai-knowledge-admin

安装必要依赖


cd ai-knowledge-admin
npm install element-ui axios mockjs echarts vuex@3 vue-router@3

启动本地开发服务器


npm run serve

构建生产环境包


npm run build
